## Rules the contract left open
R1 (A1, B1, B2) Base raster lifecycle. Started once per tile source (at init / first non-ignored callback), never re-started from a callback at z > baseMaxZoom. On success: mark ready, record jobOk (a successful base raster resets the G2 run, iOS behaviour), ask the view to re-plan. Blank verdict: sticky blank. On failure (renderError or outOfMemory): counted once in G2; it may be re-attempted only when a tile at z <= baseMaxZoom is wanted and no attempt is in flight, each attempt counted. No half-budget OOM retry and no mid-session change of basePlan/baseMaxZoom: Android drops the halving. [fixture: failureAccounting steps {op: jobOk, path: baseRaster} resetting a run, and base failure counted once]
R2 (B3, A6) A job counts once it has started executing, whether or not anyone is still waiting: it records jobOk/jobFailed in G2 and (vector jobs) feeds the EWMA. A job cancelled before it started has no effect on either. iOS changes G2 counting to per started job; E1 wording amended to "cancelled before start". [fixture: failureAccounting case with an abandoned started job]
R3 (A2, C1) EWMA / jobMs timing covers the page draw through the end of the warp only: excludes document/page open, guard arm, base-raster fetch. Android moves its timer inside withPage after open() and the guard arm; Android's estimate awaits the base raster before the sample loop. J2 states jobMs excludes the base fetch.
R4 (C2) A document-level failure in any estimate sample (cannotOpen, passwordProtected, pageMissing, pageGeometry, blank base raster) fails the whole estimate as renderFailed on both. Other sample failures are skipped (fallbacks if none count). iOS measure() checks raster.blank and document-class errors.
R5 (B5) Staged region empty, or required <= 0 or non-finite: renderError (counted) on both. Written into contract C step 3.
R6 (C3, C5) attachBake returns attached | sourceChanged | writeFailed on both; seal/commit failure is writeFailed, full disk routed through the noSpace classifier. MBTiles writers keep the FIRST error code (iOS change).
